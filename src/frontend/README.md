# Frontend Notes

This frontend is part of the `OpenLayers PostGIS .NET React Demo` workspace.

For the main setup, start, stop, and local development instructions, use the root README:

```text
../../README.md
```

## Local Frontend Commands

Start only the frontend:

```bash
npm run dev
```

Build the frontend:

```bash
npm run build
```

Run the frontend lint check:

```bash
npm run lint
```
